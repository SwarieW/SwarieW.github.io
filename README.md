# Portfolio GitHub 🚀
Selamat datang di repositori portfolio saya! 
## 🚧 Status: In Development

Website portfolio ini sedang dalam tahap pengembangan. Saat ini website menampilkan "Landing Page" sementara dengan animasi background interaktif menggunakan HTML5 Canvas.

## ✨ Fitur Animasi "Tech & Nature"
*   **Infrastruktur Jaringan:** Terdapat menara BTS sentral di tengah dan BTS satelit di sekelilingnya.
*   **Dynamic Pulse Signal:** Menara memancarkan gelombang sinyal yang beresonansi. Warna gelombang berubah dari **Hijau (stabil) -> Merah -> Hitam (pudar)** saat membesar.
*   **Kabel Fiber Optic:** Garis backbone dari dasar laut terhubung ke menara, dengan gradien warna Hijau di dasar hingga Merah saat mencapai menara.
*   **Robo-Fish & Wi-Fi:** Ikan di kejauhan yang berenang kaku layaknya robot, memancarkan sinyal Wi-Fi.
*   **Code Clouds & Matrix Rain:** Di atas permukaan laut terdapat awan berisi barisan kode kompleks yang bergerak terus menerus, sesekali menurunkan hujan biner (0 & 1).
*   **Ocean Ambience:** Gelembung air, warna dasar laut biru pekat, dan efek kedalaman.

## 🛠️ Cara Menggunakan
1.  *Clone* atau unduh repositori ini.
2.  Buka file `index.html` menggunakan browser modern (Chrome, Firefox, Safari, Edge).
3.  **Kustomisasi:**
    *   Buka `index.html` dengan *code editor*.
    *   Cari tag `<img>` di dalam `<div class="portfolio-container">`. Ganti URL `src` dengan path foto aslimu.
    *   Ubah bagian `<h1>Nama Kamu</h1>` dengan namamu.
    *   Sesuaikan deskripsi bio singkat di tag `<p class="bio">`.

## ⚙️ Teknologi yang Digunakan
*   HTML5
*   CSS3 (Glassmorphism & CSS Animations)
*   Vanilla JavaScript (Canvas API 2D)
